GUIとCLI

UI（ユーザーインターフェース）とは？

人間とコンピュータが情報をやり取りするための接点（操作画面や操作方法の仕組み）のこと。

コンピュータを操作する方法には、大きく分けて「GUI」と「CLI」の2種類があります。

GUI（グラフィカルユーザーインターフェース）とは？

画面上のアイコンやボタン、ウィンドウなどを、マウスやタッチ操作で直感的に操作する方式です。

  • メリット：視覚的にわかりやすく、初心者でも直感的に操作できる。
  • デメリット：画面描画にパソコンの処理能力（メモリやCPU）を使う。同じ作業を100回繰り返すような自動化が苦手。
  • 主な利用場面：普段の事務作業、Webブラウジング、デザイン制作など。

CLI（コマンドラインインターフェース）とは？

黒い画面（ターミナルやコマンドプロンプトなど）に、キーボードから文字（コマンド）を打ち込んで操作する方式です。日本では「CUI（キャラクターユーザーインターフェース）」と呼ばれることもあります。

  • メリット：画面描画の負荷が少なく動作が軽い。コマンドを並べてファイル化（スクリプト化）することで、作業の自動化が簡単にできる。
  • デメリット：コマンドを覚える必要があり、最初はとっつきにくい。打ち間違いによる誤操作に注意が必要。
  • 主な利用場面：サーバーの遠隔操作、開発ツールの実行、ファイルの一括処理・自動化など。

CLIを使うときに立ち上げるアプリ（端末）

OSによって、コマンドを入力する画面（アプリ）の名称が異なります。

  • Windows：コマンドプロンプト、PowerShell（パワーシェル）、Windows Terminal
  • macOS：ターミナル（Terminal）
  • Linux：ターミナル、コンソール、shell

まとめ

GUI と CLI とは⋯

マウスで画面のアイコンやボタンを直感的に操作するのが GUI、

キーボードから文字（コマンド）を打ち込んで効率よく操作するのが CLI です。

日常の操作は GUI が便利ですが、ITの開発業務では CLI を主に使います。

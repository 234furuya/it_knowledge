CLIでよく使う基本コマンド

コマンド操作の基本の考え方

CLIにはマウスカーソルがないため、常に「現在地（カレントディレクトリ）」を起点にして操作を行います。

macOSとLinuxは基本コマンドが共通しています。Windowsは「コマンドプロンプト」と「PowerShell」で書き方が異なるものがあるため、あわせて記載しています。

1. ディレクトリ（フォルダ）の確認・移動

自分が今どこにいて、中に何があるかを確認し、目的の場所へ移動するための基本コマンドです。

やりたいこと macOS / Linux Windows
（コマンドプロンプト / PowerShell）
現在の場所（パス）を確認する pwd cd（引数なし）
※PowerShellは pwd も可
語源・補足：Print Working Directory（作業ディレクトリを表示）
フォルダ内のファイル一覧を表示 ls dir
※PowerShellは ls も可
語源・補足：List（一覧表示） / Directory
ファイル一覧を詳細付きで表示 ls -l dir
※PowerShellは ls（標準で詳細表示）
語源・補足：-l（long）オプションを付けると、権限・サイズ・更新日時なども確認できます。
作業フォルダを移動する cd フォルダ名 cd フォルダ名
語源・補足：Change Directory。cd .. で1つ上の階層へ戻ります。

2. ファイル・ディレクトリの作成・複製・移動・削除

マウスでの「右クリック → 新規作成 / コピー / 削除」に相当する操作を行うコマンドです。

やりたいこと macOS / Linux Windows
（コマンドプロンプト / PowerShell）
新しいフォルダを作成する mkdir フォルダ名 mkdir フォルダ名
語源・補足：Make Directory（ディレクトリ作成）
空のファイルを作成する touch ファイル名 type nul > ファイル名
※PowerShellは ni ファイル名
語源・補足：新規の空ファイル作成や、既存ファイルの更新日時変更に使います。
ファイルをコピーする cp コピー元 コピー先 copy コピー元 コピー先
※PowerShellは cp も可
語源・補足：Copy（コピー）。設定変更前のバックアップ作成などで頻出です。
ファイルを移動・名前変更する mv 移動元 移動先 move 移動元 移動先
※PowerShellは mv も可
語源・補足：Move（移動）。同じフォルダ内で別名を指定すると名前変更になります。
ファイルを削除する rm ファイル名 del ファイル名
※PowerShellは rm も可
語源・補足：Remove（削除）。ゴミ箱に入らず即完全削除されるため注意。
フォルダを中身ごと削除する rm -r フォルダ名 rmdir /s フォルダ名
※PowerShellは rm -r フォルダ名
語源・補足：-r（recursive：再帰的）を付けることで、フォルダ内のファイルごと削除します。

3. ファイルの閲覧・編集

CLI画面上でテキストファイルや設定ファイルの中身を確認したり、直接書き換えたりするコマンドです。

やりたいこと macOS / Linux Windows
（コマンドプロンプト / PowerShell）
ファイルの中身を表示する cat ファイル名 type ファイル名
※PowerShellは cat も可
語源・補足：Concatenate（連結して出力）。短い設定ファイルやログの確認に使います。
CLI上でファイルを編集する nano ファイル名 notepad ファイル名（メモ帳起動）
※標準のCLIエディタはなし
語源・補足：画面下部に操作ショートカットが表示されるため、初心者でも扱いやすいテキストエディタです（終了は Ctrl + X）。

4. 通信・システム情報・終了

リモートサーバーへの接続や、ログイン状況・日時の確認、作業の終了に使うコマンドです。

やりたいこと macOS / Linux Windows
（コマンドプロンプト / PowerShell）
別サーバーへ安全に遠隔接続する ssh ユーザー名@ホスト名 ssh ユーザー名@ホスト名
語源・補足：Secure Shell（セキュアシェル）。通信を暗号化してLinuxサーバー等にログインします（Windows 10/11でも標準搭載）。
ネットワークの疎通確認をする ping 宛先(IPやドメイン) ping 宛先(IPやドメイン)
語源・補足：対象のサーバーやネットワークに正しく通信が届くか確認します（全OS共通）。
現在ログイン中のユーザーを確認 who query user（または whoami）
語源・補足：サーバーに今誰がログインしているかを一覧表示します。自分自身だけを確認したい場合は whoami を使います。
現在の日付・時刻を確認する date date /t と time /t
※PowerShellは Get-Date
語源・補足：サーバーのシステム時刻（タイムゾーンが日本時間かUTCか等）を確認するときによく使います。
シェルや遠隔接続を終了する exit exit
語源・補足：ssh でのリモート接続の切断や、ターミナル画面を閉じるときに使います（全OS共通）。

知っておくと便利なショートカット・機能

  • Tabキー（入力補完）：ファイル名やフォルダ名を途中まで打って Tab キーを押すと、残りを自動入力してくれます（打ち間違い防止に必須）。
  • ↑ / ↓ キー（履歴呼び出し）：過去に実行したコマンドを呼び出して再利用できます。
  • Ctrl + C（強制終了）：処理が止まらなくなったときや、入力中のコマンドを取り消したいときに使います。
